# delolder — удаление старых файлов из заданных каталогов
Консольная утилита на bash для поиска и удаления обычных файлов, время последней модификации которых превышает заданное количество дней.

## Синтаксис
delolder [-v|-d] N [--] каталоги...

### Аргументы

- `N` — целое положительное число дней. Файлы, изменённые **более чем N дней назад**, подлежат удалению.
- `Каталоги` — один или несколько путей к каталогам, в которых выполняется поиск. Повторяющиеся пути игнорируются (сохраняется первое вхождение).

### Опции

| Опция | Действие                                                                                                    |
|-------|-------------------------------------------------------------------------------------------------------------|
| `-v`  | **Verbose** – выводит полные имена удаляемых файлов и удаляет их.                                           |
| `-d`  | **Dry-run** – только выводит имена файлов, которые были бы удалены. Реального удаления не производит.       |
| `--`  | Завершает разбор опций. Всё, что идёт после `--`, считается именем каталога, даже если начинается с дефиса. |

Если не указаны ни `-v`, ни `-d`, скрипт выполняет **тихое удаление** – файлы удаляются без вывода в stdout.

Опции и каталоги могут следовать в произвольном порядке, но `N` всегда должно идти первым неопциональным аргументом.

### Коды возврата

- `0` – успешное завершение (даже если файлов для удаления не найдено).
- `1` – ошибка в аргументах (неизвестная опция, отсутствует количество дней или список каталогов, некорректный формат дней).

## Примеры

```bash
# Проверить, какие файлы будут удалены из трёх каталогов
bash ./delolder.sh -d 10 tmp obj backup

# Удалить файлы старше 30 дней из /var/log с выводом имён
bash ./delolder.sh -v 30 /var/log

# Удалить старые файлы из каталога с именем "-d"
bash ./delolder.sh 10 -- -d

# Ошибка: неизвестная опция
bash ./delolder.sh 10 dir1 -dir3
```

## Требования
- Bash ≥ 3.2 (поддержка ассоциативных массивов для удаления дубликатов).
- Стандартные утилиты: find, cat, echo.
